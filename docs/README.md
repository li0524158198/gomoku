代码本体在上级目录：

```
gomoku/
├── index.html          游戏本体（引擎 / UI / 在线客户端 全内嵌）
├── gomoku-server.js    在线对战服务器（零依赖，node gomoku-server.js [端口]）
├── test-engine.mjs     引擎单元测试（node test-engine.mjs）
├── README.md           用户文档
└── docs/               本目录（设计与开发文档）
```

> 阅读建议：想快速上手看 `01`；想改 AI 看 `02`；想加新功能先看 `06` 里对应轮次的踩坑记录，能避开大部分坑。
