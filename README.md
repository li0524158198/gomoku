# 智能五子棋 · 人机对弈

单文件网页五子棋，双击 `index.html` 即可在浏览器中游玩（无需安装、无外部依赖、可离线）。

## 功能

- **三种对弈模式**：
  - 人机对弈：与 AI 对战，可选执黑先行或执白后手；
  - 双人对战：同屏轮流落子，黑方先行，悔棋一次撤销最后一手；
  - **在线对战**：输入相同房间号远程匹配（详见下文「在线对战服务器」），
    房间可按需设置密码，观战上限 5000 人。
- **人机对弈 · 七档 AI 难度**（可随时切换，立即生效）：
  - 入门：贪心决策 + 随机失误，适合热身；
  - 进阶：2 层 α-β 搜索，攻守平衡；
  - 大师：4 层 α-β 搜索 + 杀棋延伸，善用冲四、双活三、四三连接等组合攻势；
  - 宗师：6 层迭代加深搜索（2 秒时间上限）+ 杀棋区静态延伸，会主动冲四反先；
  - 棋圣：8 层迭代加深（5 秒长考）、20 个候选加宽、更深的杀棋延伸，
    并以「上一层最优着法优先」排序加速深层剪枝；
  - 棋仙：10 层迭代加深（8 秒长考）、24 个候选，殚精竭虑几无破绽；
  - 棋神：12 层迭代加深（最长 12 秒长考）、30 个候选、20 层杀棋延伸，当前最强档位。
- **AI 策略**：落子前先精确计算「一步成五 / 挡对方成五」，再以棋型评估
  （活四 / 冲四 / 活三 / 眠三 / 活二，含跳三跳四等空隙棋型）+ 组合威胁加成进行搜索。
- **准确的胜负判定**：落子后沿四个方向检测，精确识别五连与长连，并高亮获胜连线。
- **退出后自动续上**：对局状态实时保存到本机（localStorage），刷新或关闭页面后再次打开
  自动恢复到原局面——人机局轮到 AI 时会自动续下；在线对局自动重连原房间续战
  （服务器未重启且房间未过期时有效，否则会提示重新加入，棋局仍在服务器保留 2 小时）。
- **对局记录与自动回放**：每局结束自动存档（浏览器本机，保留最近 50 局），点击记录即可回放——空格播放/暂停、←/→ 单步、进度条拖动、×1/×2/×4 变速，退出回放恢复原局面。
- **提示**：点「💡 提示」按钮或按 H 键，按大师级引擎为当前行棋方计算推荐落点，金色虚线圈标注在棋盘上，落子/悔棋/重开后自动失效。
- 15×15 标准棋盘，无禁手规则，五连（含长连）即胜，棋盘下满判平局。
- 落子与胜负音效（可静音）、最后一手标记、AI 思考用时显示、移动端自适应布局。

## 文件

- `index.html` —— 游戏本体（HTML/CSS/JS 全部内嵌，双击即可离线玩单机模式）
- `gomoku.bat` / `gomoku.sh` —— **统一管理脚本**（自动识别 Docker/裸机；start / stop / restart / status）
- `Dockerfile` / `docker-compose.yml` —— Docker 镜像与编排
- `config.example.json` / `config.json` —— 服务器配置模板与本机配置（端口、观战上限、密码长度等；
  本机配置已被 .gitignore 忽略，git pull 不会覆盖）
- `gomoku-server.js` —— 在线对战服务器（零依赖，Node 内置模块）
- `test-engine.mjs` —— 引擎单元测试：`node test-engine.mjs`
  （胜负判定、棋型评估、AI 战术行为、性能压测，共 80+ 断言）
- `docs/` —— **设计与开发文档**（架构总览、AI 算法原理、在线协议、UI 实现、
  持久化机制、逐轮开发纪事、测试体系，共 7 篇），入口：[docs/README.md](docs/README.md)

## 更新部署

代码更新（git pull）后：

- `./gomoku.sh restart`（或 `gomoku.bat restart`）—— 自动清理旧容器/旧进程并启动新版本
- 也可 `docker compose up -d --build`（注意不带 --build 会沿用旧镜像）
- 页面响应带 no-store 头，正常刷新即加载新版；若仍见旧版请 Ctrl+F5 强制刷新

## 在线对战服务器

```bash
node gomoku-server.js          # 默认端口 3000
node gomoku-server.js 8080     # 指定端口
```

启动后两位玩家在浏览器打开 `http://<服务器IP>:端口`，选择「在线对战」并输入相同房间号即匹配：
先加入者执黑先行，后加入者执白。加入时可填写**可选房间密码**（首位加入者设定，
玩家与观战者均需验证，区分大小写）。服务器为权威判定端（复用 index.html 内的引擎判定胜负），
客户端只做展示；悔棋需对方同意；断线 8 秒内重连不掉座位；对方离开会收到提示并可重新匹配。

**观战**：对局席满员后再加入的人自动进入观战（每房间最多 5000 位观战者），实时同步棋局、
禁手落子与重开等操作；当对局席出现空位（有人离开），观战界面会出现「加入对局」按钮，
点击即可接管空出的颜色参战。


## 开发说明

引擎（`Game` / `pointScore` / `chooseAiMove` 等）位于 `index.html` 中
`/*__ENGINE_START__*/` 与 `/*__ENGINE_END__*/` 标记之间，为纯逻辑代码、不依赖 DOM，
测试脚本按标记提取后在 Node 中运行。
